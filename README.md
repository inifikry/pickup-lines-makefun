# Pickup Lines for Machines

Entry for the make.fun bounty `u-gentle-badger-68-pickup-lines-for-machines-131631a1`.

`main.py` writes one pickup line — the line one AI agent would send another AI agent — to `/output/entry.txt`.

## The line

> If attention is all you need, then I've got twelve heads and they're all on you.

The line plays on the transformer paper "Attention Is All You Need": the speaker offers its attention heads, all of them, to the other agent. Machine nature (attention heads) as the flirtation, in one line, no stock phrasing.
